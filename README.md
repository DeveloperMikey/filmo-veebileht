# filmo-veebileht

Repositooriumis on Tartu Ülikooli sissejuhatus erialasse aine veebilehe projekti raames koostatav veebileht CTF (Capture the flag) mängu mängimiseks.

Tiimiliikmed on Mihkel Mäemets, Joonas Piit ja Sten Kuld. Igaüks koostas 2 lehte: Sten krüptograafia ül-d, Mihkel web exploitation ül-d ja Joonas avalehe ning steganograafia ülesanne. Lisaks tegi Mihkel backendi ning koostöös Joonasega mõningad JS elemendid. Sten valmistas lehtedele ühtse css-i.
